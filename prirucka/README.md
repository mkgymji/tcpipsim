# Příručka pro učitele

Materiály pro učitele k simulátoru tcpipsim (https://mkgymji.github.io/tcpipsim/).
Vývojářská dokumentace je ve složce `docs/`.

- [Tahák příkazů terminálu](tahak.md): příkazy Windows, Cisco IOS a Linux po úrovních, co ukážou
  a na co se zeptat studentů. Tisknutelná A4. Generuje se z kódu (`node tools/tahak.mjs`).

Průvodce úrovněmi (učitelská stránka ke každé úrovni) přijde po dokončení všech úrovní.
